# Barbosachat

Aplicação de mensagens para Android e iPhone, construída com Expo e React Native.

## Estado atual

Esta é a primeira base visual do projeto:
- interface inicial em português, com identidade verde própria;
- separadores de Conversas, Contactos e Definições;
- lista de conversas demonstrativa e pesquisa local;
- preferência de tradução automática demonstrativa, desligada por defeito;
- idioma de demonstração: Português.

## Executar localmente

```bash
npm install
npx expo start
```

## Próximas etapas

1. Definir e implementar autenticação e perfis.
2. Ligar uma base de dados e mensagens em tempo real.
3. Implementar envio de texto, fotografias, vídeos e áudio.
4. Adicionar notificações e chamadas de voz/vídeo.
5. Implementar privacidade, segurança e preferências individuais persistentes.

As conversas e a opção de tradução nesta primeira versão são apenas demonstrações locais. Ainda não existe backend nem envio real de mensagens.
